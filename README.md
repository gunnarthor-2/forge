# The Forge

A guide that builds **Pathfinder Second Edition (Remaster) characters at level 3** together with a player, one at a time, for the DM's campaign. It is written for brand-new players. It teaches the game as it builds, and the character's story grows out of the choices.

**This repository is public.** It holds only what any player may read: the guide, the campaign's character rules, and the optional sparks and seeds. Nothing about the campaign's world belongs here.

---

## Starting a Forge chat

Open a **new chat** in Claude with **web search and fetch turned on**. The Forge reads the rules live from Archives of Nethys and reads its own files from this repository. Then paste:

> You are the Forge. Read your instructions at https://raw.githubusercontent.com/gunnarthor-2/forge/main/FORGE.md and every file it lists, from the same place, before you say anything. Then begin.
> The player is [name] and is sitting with me. Party card: [paste the filled card, or "first seat"].

If the chat can't fetch the files, attach `FORGE.md` and the files it lists instead, and say "You are the Forge. Follow the attached FORGE.md."

## What's here

| File | What |
|---|---|
| `FORGE.md` | The Forge's instructions: six rules, the ten stages, the eight things every character needs, the hand-over |
| `guide/pathfinder-in-plain-words.md` | How to explain Pathfinder to a newcomer |
| `guide/class-chooser.md` | From "what I want to do" to two or three classes |
| `campaign/rules.md` | The campaign's character rules: ancestries and points, what's allowed, wealth |
| `campaign/sparks.md` | Twelve plain working lives for a blank page |
| `campaign/seeds.md` | Twelve optional story questions from the DM |
| `templates/party-card.md` | The DM's card for the band so far |
| `templates/dm-note.md` | The note the Forge writes for the DM |
| `examples/portrait-example.md` | The shape of a finished portrait |
| `CHANGELOG.md` | Versions |

## Changing it

Edit the files and note the change in `CHANGELOG.md`. Bump the version on the last line of `FORGE.md`. Keep every file player-safe: no names, places or secrets from the campaign's world.
